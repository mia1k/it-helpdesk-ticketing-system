
# IT Help Desk Ticketing System

## Project Overview

A Java-based IT Help Desk Ticketing System developed to
simulate how an organisation manages technical support
requests and incidents.

The application allows users to create, manage, search
and track support tickets.

## Features

- Create support tickets
- Validate ticket information
- Categorise technical issues
- Assign priority levels
- Update ticket statuses
- Search tickets by ID
- Filter tickets by status
- Save and retrieve ticket records using CSV file storage

## How to Run

1. Install Java JDK 21 or later.
2. Clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the src folder.
5. Run Main.java.
